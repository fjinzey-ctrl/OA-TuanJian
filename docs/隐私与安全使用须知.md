密码需为 12–128 位，建议使用不在其他网站复用的长短语。附件在线预览在平台自己的鉴权范围内按需加载，Office 文件在本机浏览器内存中解析，不会发送到第三方在线文档转换服务；预览能力有限时请下载并使用可信的本机软件打开。

访问量接近每日免费额度时，平台会切换到不读取业务数据的静态高峰提示页。该状态不会删除账号、内容、团费记录或附件；额度重置后完整站点自动恢复。

## Cookie 与本地记录

- 必要 Cookie 用于保持登录、执行安全退出、限制会话寿命并防止伪造请求；其内容是随机会话标识，不保存正文、附件或密码。
- 浏览器本地记录用于保存界面偏好、通知查看状态和隐私选择版本，减少重复提示；清除浏览器数据后可能需要重新选择。
- Cloudflare 安全检测可能使用风险控制所需的 Cookie，以判断登录或匿名资料访问是否来自真实浏览器。
- 登录页、桌面侧栏、右上角齿轮和手机工具抽屉均可通过小饼干图标查看通俗说明。现有和新成员都必须明确选择；不接受时平台会安全退出。
- 普通会话在持续使用网站时保持 24 小时活动窗口；选择记住设备后可在 30 天内恢复。主动退出、撤销设备或修改密码后，相应登录会失效。
- 设备页可展示浏览器、系统、设备类型、用户自定义名称、在线状态、本站活动时间，以及 Cloudflare 提供的粗粒度国家、地区、城市和网络服务商；不展示完整 IP，不读取系统用户名或浏览器个人资料名称。

## 请勿公开

- 账号、密码和一次性初始密码。
- 成员名单、完整学号列表和内部身份信息。
- 团费二维码、缴费凭证和缴费备注。
- 公示附件、活动内部材料和支部备份压缩包。
- 通知中仅限内部使用的图片或附件。

## 文件使用

- 带有个人信息、时间或用途标记的文件仅供授权场景使用。
- 不要删除、遮挡或故意规避文件中的身份标记。
- 受保护的 PDF 和图片只有在水印衍生文件生成成功后才会提供；处理失败时不会回退下载原文件。
- 无法在线预览不代表文件可以公开传播。
- 下载到本地后，应使用受控设备保存，并在不再需要时妥善删除。

## 账号使用

- 每人只使用自己的账号。
- 首次登录后立即修改初始密码。
- 不在公共设备上保存密码。
- 发现异常身份、未知通知或异常文件访问时，应立即反馈。

## 公开反馈

GitHub Issues 是公开区域。反馈时请使用功能名称、页面名称、发生时间和经过脱敏的截图，不要上传任何内部附件或个人敏感信息。

# Privacy and Safe-Use Notice

When traffic approaches the daily free allowance, the platform switches to a static peak-traffic notice that does not read business data. This state does not delete accounts, content, fee records, or attachments; the full site returns automatically after the allowance resets.

## Do Not Publish

- Accounts, passwords, or one-time initial passwords.
- Member rosters, complete student ID lists, or internal role information.
- Fee QR codes, payment evidence, or payment notes.
- Notice attachments, internal activity materials, or branch backup archives.
- Images or attachments in notifications that are intended only for internal use.

## File Use

- Files marked with personal information, time, or purpose are for authorized use only.
- Do not remove, conceal, or intentionally bypass identity markings in a file.
- A file's inability to be previewed online does not mean that it may be distributed publicly.
- Store downloaded files on controlled devices and delete them securely when no longer needed.

## Account Use

- Each person must use only their own account.
- Change the initial password immediately after the first sign-in.
- Do not save passwords on public devices.
- Report an unexpected role, unknown notification, or unusual file access immediately.

## Public Feedback

GitHub Issues is a public area. When submitting feedback, provide feature names, page names, occurrence times, and redacted screenshots. Do not upload internal attachments or personal sensitive information.
# 2.1 缓存与验证说明

平台仅长期缓存带指纹的公开静态程序资源；头像采用用户私有短期缓存，受保护正文附件和水印文件继续禁止长期浏览器缓存。人机验证仍由服务端强制核验，客户端快速重试和手动重试均不会绕过验证。
# 安全提醒使用的数据边界

平台会对短时间内大量下载、同一账号多个网络来源登录、反复提交无效或危险头像链接做阈值提醒。提醒只包含账号、时间窗、次数、不可逆 IP 哈希或域名哈希，不保存或展示原始 IP、完整头像链接、附件正文和浏览内容。系统管理员应把提醒当作核对线索，而不是自动认定违规。

外链头像只接受公开 HTTPS 图片，拒绝内网地址、账号密码式地址、非常用端口和跳转；读取最长约 6 秒、最大 1 MB，并核对文件类型与文件头。未通过时内容不会保存。

网址以 `.jpg`、`.png` 等结尾不代表响应一定是图片。若远端实际返回登录页、网页或动态安全验证页，平台不会执行对方脚本或绕过验证，而会提示改用无需登录、可直接返回图片文件的公开图床地址。
