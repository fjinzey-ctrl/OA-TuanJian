# 隐私与安全使用须知

密码需为 12–128 位，建议使用不在其他网站复用的长短语。附件在线预览在平台自己的鉴权范围内按需加载，不会把内部文件发送到第三方在线文档转换服务；预览能力有限时请下载并使用可信的本机软件打开。

## 请勿公开

- 账号、密码和一次性初始密码。
- 成员名单、完整学号列表和内部身份信息。
- 团费二维码、缴费凭证和缴费备注。
- 公示附件、活动内部材料和支部备份压缩包。
- 通知中仅限内部使用的图片或附件。

## 文件使用

- 带有个人信息、时间或用途标记的文件仅供授权场景使用。
- 不要删除、遮挡或故意规避文件中的身份标记。
- 无法在线预览不代表文件可以公开传播。
- 下载到本地后，应使用受控设备保存，并在不再需要时妥善删除。

## 账号使用

- 每人只使用自己的账号。
- 首次登录后立即修改初始密码。
- 不在公共设备上保存密码。
- 发现异常身份、未知通知或异常文件访问时，应立即反馈。

## 公开反馈

GitHub Issues 是公开区域。反馈时请使用功能名称、页面名称、发生时间和经过脱敏的截图，不要上传任何内部附件或个人敏感信息。

# Privacy and Safe-Use Notice

## Do Not Publish

- Accounts, passwords, or one-time initial passwords.
- Member rosters, complete student ID lists, or internal role information.
- Fee QR codes, payment evidence, or payment notes.
- Notice attachments, internal activity materials, or branch backup archives.
- Images or attachments in notifications that are intended only for internal use.

## File Use

- Files marked with personal information, time, or purpose are for authorized use only.
- Do not remove, conceal, or intentionally bypass identity markings in a file.
- A file's inability to be previewed online does not mean that it may be distributed publicly.
- Store downloaded files on controlled devices and delete them securely when no longer needed.

## Account Use

- Each person must use only their own account.
- Change the initial password immediately after the first sign-in.
- Do not save passwords on public devices.
- Report an unexpected role, unknown notification, or unusual file access immediately.

## Public Feedback

GitHub Issues is a public area. When submitting feedback, provide feature names, page names, occurrence times, and redacted screenshots. Do not upload internal attachments or personal sensitive information.
