# 通知、备份与支部删除说明

通知详情中的“前往相关页面”会在跳转前自动关闭详情和通知中心。通知中心支持仅看未读和全部标为已读；查看过列表但尚有未逐条阅读内容时，铃铛使用小红点提示，后续新通知或同一内容再次异动后恢复数字提示。

同一内容首次发布后只保留一条通知，后续修改更新该通知并追加完整异动时间线。已经读过的通知会重新变为未读；尚未阅读时仍保持一条未读，不重复堆积。新成员不集中接收加入前的支部消息，只看到欢迎通知以及近两个月全平台通知；该时段为空时回退最近两条。

## 通知类型

- 平台通知：由系统管理员发布，可面向全平台或指定支部。
- 内容通知：本支部发布新公示、团建或团费内容时自动产生。
- 身份通知：成员被任命或调整为管理员、编辑、普通成员时自动产生。
- 支部资料通知：系统管理员修改支部信息时发送给该支部管理员。
- 备份通知：系统管理员完成支部备份后发送给该支部管理员。
- 删除流程通知：包含删除申请、管理员决定和最终处理状态。
- 设置与内容更新通知：支部设置或已发布内容发生变化时自动产生。
- 平台升级通知：系统升级后自动向相关用户说明本次可见变化。

所有自动管理通知都会尽量注明操作人、操作时间和变更明细。系统管理员可在分类存档中按类型、范围和关键词查找人工与自动通知；支部正文继续保持隔离。页面中的管理时间统一标注为北京时间 GMT+8:00。

## 备份内容

完整支部备份包括：

- 公示、团建和团费内容。
- 草稿、已发布和已归档状态。
- 作者、日期、发布时间和修改记录。
- 内容对应的原附件。
- 支部基础信息和组织信息。
- 成员账号基础信息与身份。
- 当前缴费状态和历史缴费归档明细。

备份文件按模块和内容条目整理，便于离线查阅与长期保存。

## 删除审批规则

1. 系统管理员完成并下载最新版备份。
2. 系统管理员发起本轮支部删除申请。
3. 支部管理员在通知中选择同意或不同意，并进行二次确认。
4. 首位提交的管理员决定锁定本轮申请。
5. 决定结果通知系统管理员和支部全体成员。
6. 只有获同意且数据未再变化时，系统管理员才能再次确认永久删除。

若本轮被拒绝，系统管理员需要在条件具备后发起新一轮申请。

# Notifications, Backups, and Branch Deletion

## Notification Types

- Platform notification: published by a system administrator to the whole platform or selected branches.
- Content notification: generated automatically when a branch publishes a new notice, activity review, or fee item.
- Role notification: generated automatically when a member is appointed or reassigned as an administrator, editor, or ordinary member.
- Branch-details notification: sent to branch administrators when a system administrator changes branch information.
- Backup notification: sent to branch administrators after a system administrator completes a branch backup.
- Deletion-process notification: covers the deletion request, an administrator's decision, and final processing status.
- Settings and content-update notification: generated automatically when branch settings or published content changes.
- Platform-release notification: generated after a system update to explain user-visible changes.

Every automatic administrative notification identifies the operator, operation time, and detailed changes whenever applicable. System administrators can find both manual and automatic notifications in a categorized archive by type, scope, and keyword, while branch content remains isolated. Administrative times shown on the page are labeled Beijing Time GMT+8:00.

## Backup Contents

A complete branch backup includes:

- Notices, activity reviews, and Youth League fee content.
- Draft, published, and archived statuses.
- Authors, dates, publication times, and revision records.
- Original attachments associated with each content item.
- Basic branch and organization information.
- Basic member account information and roles.
- Current fee statuses and detailed historical fee archives.

Backup files are organized by module and content item for convenient offline review and long-term retention.

## Deletion Approval Rules

1. A system administrator completes and downloads the latest backup.
2. The system administrator initiates the current branch-deletion request.
3. A branch administrator selects Approve or Reject in the notification and confirms the decision a second time.
4. The first submitted administrator decision locks the current request.
5. The decision is sent to the system administrator and every member of the branch.
6. Permanent deletion can be confirmed only when the request was approved and the branch data has not changed.

If the current request is rejected, the system administrator must initiate a new request after the required conditions are met.
# 2.1 通知附件说明

通知正文图片与附件区文件均通过登录鉴权地址读取。系统通知存档会保留附件名称、类型和入口；是否显示在正文或附件区由发布者分别决定。备份与删除规则不因本次显示修复而改变。
