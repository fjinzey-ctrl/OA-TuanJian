# 完整功能总览

## 登录与账户

- 使用平台分配的学号和密码登录。
- 初始密码未修改时，登录后会优先要求设置新密码。
- 密码修改后，其他设备上的旧登录状态会失效。
- 所有用户均可上传头像，并可拖动、缩放和裁剪圆形头像区域。
- 姓名由管理员统一维护，成员不能自行更改，以保证身份展示和文件标记一致。

## 首页

- 按北京时间显示“xx好！xxx同志”的问候。
- 展示近期公示、近期团建活动和当前团费状态。
- 功能卡片支持整卡点击，同时保留明确的“点击查看”提示。
- 当前没有已发布团费内容时，首页会显示中性空状态，不会误导成员缴费。

## 公示栏

- 查看本支部已发布公示，支持搜索、筛选和排序。
- 进入详情后查看富文本正文、附件预览及修改记录。
- 公示附件可嵌入正文；需要保护的文件会在预览或下载时显示与当前用户相关的标记。
- 编辑历史包括操作人、状态变化、修改摘要和时间，并面向本支部成员公开。

## 团建回顾

- 查看本支部活动回顾、图片、文字记录和附件。
- 活动图片可在正文中自由编排，首页可展示近期活动封面。
- 详情页面提供同模块内容导航，便于连续浏览。

## 团费缴纳

- 查看当前团费通知和本人的缴纳状态。
- 提交“我已缴纳”后，等待管理员核对确认。
- 成员可查看本支部各成员的姓名和缴纳状态，但普通成员页面不公开学号。
- 管理员可逐人或批量确认缴纳状态。
- 每期团费通知只对应一组有效缴费归档；归档包含逐成员明细。
- 符合条件时可填写原因撤销归档，撤销后可重新建立有效归档。

## 团徽、团旗、团歌与规范资料

- 对所有已登录用户开放，不受支部限制。
- 使用规范采用点击后加载的预览方式。
- 每项资料可预览或下载，页面针对手机和桌面分别提供适合的操作方式。
- 资料仅由系统管理员维护。

## 通知中心

- 接收平台通知、支部新内容、身份变化、支部资料变化、支部备份和删除申请决定。
- 未读通知具有明确标记，点击后打开详情卡片并自动变为已读。
- 通知正文支持标题、列表、强调、引用、链接、图片和附件。
- 涉及管理操作的自动通知会注明操作人、操作时间和变更明细。

## 内容与附件

- 编辑和管理员可以新建公示、团建或团费内容。
- 支持富文本排版、标题、列表、引用、链接、对齐、图片和附件插入。
- 文件可点击选择、拖入或粘贴，并显示上传进度。
- 支持草稿、已发布和已归档状态。
- 发布者自动使用当前登录者姓名，不能隐藏或修改。
- 编辑只能修改自己发布的内容，管理员可管理本支部全部内容。
- 未保存时离开页面会收到提醒；待删除附件仅在内容成功保存后正式删除。

## 成员与身份管理

- 管理员可以新增成员、批量导入成员、修改姓名、任命编辑或管理员、启停普通账号和重置密码。
- 身份发生变化时，本人会收到通知，通知中注明操作人和时间。
- 支部管理员不能移除其他管理员。
- 系统管理员可以任命或降级支部管理员，但不能降级某支部最后一名管理员。
- 删除普通账号仅由该账号所属支部的管理员执行。

## 支部资料与空间

- 支部可维护组织类别、简称、全称、所属领域、上级组织、预计毕业时间、负责人、简介和文件用途说明。
- 每个支部具有独立空间配额和使用情况展示。
- 系统管理员可查看平台实际总占用、支部业务附件、公共资料、通知附件、水印文件以及其他平台对象的分类占用。
- 平台接近免费存储额度时自动通知所有用户；达到保护阈值后暂停新增文件类操作，避免空间耗尽。

## 支部备份与删除

- 系统管理员可为单个支部生成完整备份。
- 备份包含公示、团建、团费内容、缴费统计、状态、作者、日期、修改日志、成员信息和原附件。
- 页面显示整理和下载进度，备份完成前阻止离开。
- 删除支部前必须完成最新版备份。
- 系统管理员发起删除申请后，由该支部管理员作出决定；首位管理员的决定会锁定本轮申请。
- 决定结果会通知系统管理员和支部全体成员。

## 多端体验

- 桌面端支持可收起、临时浮现并重新固定的侧边导航。
- 手机端使用底部导航和管理模块切换入口。
- 长标题、长路径、富文本、表格和文件预览均针对窄屏进行适配。
- 下载、上传、保存和备份过程提供明确的加载或进度反馈。

# Complete Feature Overview

## Sign-In and Accounts

- Sign in with the student ID and password assigned by the platform.
- If the initial password has not been changed, the platform prioritizes setting a new password after sign-in.
- After a password change, old sign-in sessions on other devices become invalid.
- Every user can upload an avatar and drag, zoom, and crop the circular avatar area.
- Names are maintained centrally by administrators. Members cannot change their own names, which keeps identity display and file markings consistent.

## Home Page

- Display the greeting “Good morning/afternoon/evening! Comrade [name]” according to Beijing time.
- Show recent notices, recent branch activities, and the current fee status.
- Feature cards support selecting the whole card while retaining an explicit “Click to View” prompt.
- If no fee content is currently published, the home page shows a neutral empty state and does not mislead members into making a payment.

## Notices

- View published notices for the member's branch, with search, filtering, and sorting.
- Open details to read rich-text content, preview attachments, and inspect revision records.
- Notice attachments can be embedded in the body. Protected files display markings related to the current user during preview or download.
- Revision history includes the operator, status change, revision summary, and time, and is visible to authorized branch members.

## Activity Reviews

- View activity reviews, images, written records, and attachments for the member's branch.
- Activity images can be arranged freely in the body, and the home page can display a recent activity cover.
- The details page provides navigation among items in the same module for continuous browsing.

## Youth League Fees

- View the current fee notice and the signed-in member's payment status.
- After selecting “I Have Paid,” wait for administrator verification.
- Members can view branch member names and payment statuses, but student IDs are not disclosed on ordinary member pages.
- Administrators can verify payment statuses individually or in batches.
- Each fee notice corresponds to only one active payment archive, and the archive includes details for every member.
- When the required conditions are met, an archive can be revoked with a reason and then recreated as a new active archive.

## Youth League Emblem, Flag, Anthem, and Official Resources

- Available to all signed-in users regardless of branch.
- Usage guidelines use a click-to-load preview.
- Each resource can be previewed or downloaded, with controls suited separately to mobile and desktop devices.
- Official resources are maintained only by system administrators.

## Notification Center

- Receive platform notifications, new branch content, role changes, branch-detail changes, branch backups, and branch-deletion decisions.
- Unread notifications are clearly marked. Selecting one opens a details card and automatically marks it as read.
- Notification content supports headings, lists, emphasis, quotations, links, images, and attachments.
- Automatic notifications involving administrative operations identify the operator, operation time, and detailed changes.

## Content and Attachments

- Editors and administrators can create notices, activity reviews, or fee content.
- Rich-text formatting supports headings, lists, quotations, links, alignment, images, and attachment insertion.
- Files can be selected, dragged, or pasted, and upload progress is displayed.
- Draft, published, and archived statuses are supported.
- The publisher is set automatically to the signed-in user's name and cannot be hidden or changed.
- Editors can modify only content they published; administrators can manage all content in their branch.
- The platform warns before leaving with unsaved changes. Attachments marked for deletion are removed only after the content is saved successfully.

## Member and Role Administration

- Administrators can add members, import members in batches, update names, appoint editors or administrators, enable or disable ordinary accounts, and reset passwords.
- When a role changes, the affected member receives a notification identifying the operator and time.
- Branch administrators cannot remove other administrators.
- System administrators can appoint or downgrade branch administrators but cannot downgrade the last administrator of a branch.
- Only administrators of the account's branch can delete an ordinary account.

## Branch Details and Storage

- Branches can maintain their organization category, short name, full name, field, parent organization, expected graduation time, person in charge, description, and file-purpose information.
- Each branch has an independent storage quota and usage display.
- System administrators can view actual total platform usage and categorized usage for branch attachments, public resources, notification attachments, watermarked files, and other platform objects.
- As the platform approaches the free storage allowance, it automatically notifies all users. At the protection threshold, it pauses new file-related operations to prevent storage exhaustion.

## Branch Backup and Deletion

- A system administrator can generate a complete backup for an individual branch.
- The backup includes notices, activity reviews, fee content, payment statistics, statuses, authors, dates, revision logs, member information, and original attachments.
- The page displays preparation and download progress and prevents leaving until the backup is complete.
- The latest backup must be completed before a branch can be deleted.
- After a system administrator initiates a deletion request, a branch administrator makes the decision. The first administrator's decision locks the current request.
- The decision is sent to the system administrator and every member of the branch.

## Multi-Device Experience

- On desktop, the side navigation can be collapsed, temporarily revealed, and pinned open again.
- On mobile, the platform uses bottom navigation and a management-module switcher.
- Long titles, long paths, rich text, tables, and file previews are adapted for narrow screens.
- Downloads, uploads, saves, and backups provide explicit loading or progress feedback.
