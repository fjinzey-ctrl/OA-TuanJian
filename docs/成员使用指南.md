# 成员使用指南

v2.1.9 将资料入口统一为“公开资料”，站内显示完整版本号 2.1.9。匿名访客可先进入资料页，安全检测在后台完成；核验异常或疑似机器行为时，页面会阻止继续停留并提供重试或返回登录页。

## 进入平台

- 访问母站后，点击右上角“登录”或页面中的“进入工作台”进入登录页。
- 无需登录查看资料时，点击“查看公开文件”即可直接进入公开页面。
- 母站中的产品窗口是使用虚构内容制作的交互演示，不代表任何真实支部或用户数据。

## 首次登录

1. 使用管理员提供的学号和初始密码登录。
2. 等待页面安全检测完成；未完成时不能提交登录。网络较慢时请让页面自行完成恢复，不要连续刷新或重复提交。
3. 阅读 Cookie 与隐私选择说明并作出明确选择；拒绝后平台会安全退出。
4. 按页面要求立即设置新密码。
5. 进入“我的”检查姓名和所属支部是否正确。
6. 如需头像，直接点击“我的”页面中的圆形头像；更换浮窗会先显示当前头像大图，再提供图片选择与裁剪。

没有支部账号或无法登录时，可直接使用登录卡片中的“联系反馈”申请支部入驻或说明问题。

新密码需要 12–128 位，可使用字母、数字、空格和符号。建议使用容易记住但难猜的长短语，不要包含姓名、学号或生日，也不要复用其他网站密码。

## 浏览内容

- 从首页卡片或导航进入公示、团建、团费和公开资料。
- 点击具体条目查看完整正文、附件和修改记录。
- 普通内容按发布时间由新到旧排列；带“置顶”标记的内容会优先显示并使用不同样式强调。
- 修改记录默认折叠，展开后按时间从新到旧排列。
- 附件名称显示不全时，把鼠标停在名称上可查看完整文件名。
- 内容较多时可使用页面提供的搜索和筛选。
- 公开资料按团务资料、现行规定和学习资料分类，卡片不展示作者或发布日期；学习资料仅登录后可见。

## 记住设备与设备管理

- 在可信的个人设备上登录时，可选择“记住此设备”，30 天内可更便捷地恢复登录。
- 普通会话在持续使用网站时保持 24 小时活动窗口；主动退出、撤销设备或修改密码仍会终止相应会话。
- “我的—设备”按设备归纳浏览器会话，展示系统、设备类型、本机、在线/离线、最近活跃、粗粒度网络地区和活动会话数；浏览器版本等详细信息默认折叠。
- 设备页提供独立刷新按钮，可为设备设置便于识别的名称，也可撤销不认识的设备；撤销本机后会退出当前登录。
- 平台不会读取操作系统用户名或浏览器个人资料名称。

## Cookie 与隐私选择

- 登录页和平台内的“小饼干”入口会说明必要 Cookie、本地偏好记录及 Cloudflare 安全检测的用途。
- 必要 Cookie 用于维持登录、安全退出和防止伪造请求，不能在已登录状态下关闭。
- 可随时从桌面侧栏、右上角齿轮或手机工具抽屉重新查看说明和当前选择。
- 选择不接受时，平台会清除登录状态并返回登录页，不会继续保持成员会话。

## 团费确认

1. 确认当前页面存在有效的团费通知。
2. 完成缴费后点击“我已缴纳”。
3. 按钮变为绿色表示已提交，最终状态以管理员核对结果为准。
4. 支部成员状态列表只展示姓名与缴纳状态。

## 文件预览和下载

- 未登录时也可从登录页进入公开规范资料，但支部公示和内部附件仍需登录。
- 点击预览区域后再加载较大的规范文件。
- 下载过程中按钮会显示加载状态，请勿连续重复点击。
- 部分内部附件会带有姓名、时间和用途信息，请妥善保管。
- 无法在线预览的文件仍可按页面提示下载后查看。
- 内嵌 PDF 默认适应页宽并向下连续浏览；手机可用双指缩放，放大后只在预览框内部横向移动。
- TXT/LOG、CSV、Markdown、JSON、XML、图片、DOCX 和 XLSX 可按需在线预览；历史 TXT 也能正常识别。团歌音频等不支持格式只提供下载，不显示文件夹预览图标。表格预览最多显示前 200 行，完整内容仍以下载文件为准。

## 遇到错误时

- 文件上传提示会写明具体文件名和检测到的原因。若提示内容与扩展名不一致，请先在本机正常打开并重新导出，不要只修改文件名后缀。
- 页面会说明本次操作是否可能尚未保存。遇到服务器错误时先刷新核对，避免连续重复提交。
- 仍然失败时，请向管理员提供操作名称、北京时间、文件类型或归档编号；无需发送账号密码。
- 若看到“当前处于访问高峰”，表示平台为保护每日服务额度暂时停止 OA 功能；数据不会丢失，请在页面提示的下一次北京时间 08:05 后重试。

## 通知

- 铃铛上的数字表示未读通知数量。
- 点击通知会在保持通知列表展开的同时打开完整详情并自动标为已读；关闭详情后可直接继续浏览列表。
- 可使用“筛选未读”只看尚未打开的消息，也可使用“全部标为已读”一次处理当前通知。
- 打开通知列表但未打开详情时会保留红点；若对应内容之后再次异动，铃铛会重新显示数字。
- 同一内容的发布与多次修改会合并在一条通知中，详情按时间保留完整异动记录。
- 新加入支部时会收到欢迎与最新版本说明；通知中心只保留近两个月全平台消息，若该时段没有消息则展示最近两条。
- 通知可能包含图片、附件或相关页面入口。
- 点击“前往相关页面”后，通知详情和通知中心会自动收起。
- 身份变化、支部重要管理决定等信息请及时阅读。

## 账户安全

- 不要把账号、密码、团费二维码或内部附件转发给无关人员。
- 发现姓名、支部或权限错误时联系本支部管理员。
- 发现异常登录或误操作时应尽快修改密码并反馈。

## 暂未加入支部

- 被原支部移出后，账号、原密码、头像和历史责任记录不会被删除。
- 该账号仍可登录，但在重新加入支部前只开放“我的”页面和反馈系统管理员的引导。
- 如需加入新支部，请联系新支部管理员；若账号仍显示属于其他支部，平台会阻止重复加入。

# Member Guide

## Opening the Platform

- From the root site, select “Sign In” or “Enter Workspace” to open the dedicated sign-in page.
- To browse resources without signing in, select “View Public Files.”
- The product window on the introduction page is an interactive demonstration made with fictional content and does not represent any real branch or user data.

## First Sign-In

1. Sign in with the student ID and initial password supplied by an administrator.
2. Wait for the page security check to complete, then submit the sign-in form after verification succeeds.
3. Set a new password immediately when prompted by the page.
4. Open “My Profile” and confirm that the displayed name and branch are correct.
5. To add an avatar, select the profile image and choose, crop, and position a picture.

If no branch account is available or sign-in fails, use “Contact Feedback” on the sign-in card to request branch onboarding or describe the problem.

## Browsing Content

- Open Notices, Activities, Youth League Fees, or Official Resources from the home-page cards or navigation.
- Select an item to read its full content, attachments, and revision records.
- When a page contains many items, use the available search, filtering, or sorting controls.

## Confirming Youth League Fees

1. Confirm that the page contains an active fee notice.
2. After completing payment, select “I Have Paid.”
3. A green button indicates that the submission was recorded. The final status is subject to administrator verification.
4. The branch payment-status list displays only member names and payment statuses.

## File Preview and Download

- Public official resources can be opened from the sign-in page without an account, while branch notices and internal attachments still require sign-in.
- Select the preview area before loading a large official document.
- During a download, the button displays a loading state. Do not select it repeatedly.
- Some internal attachments display the authorized user's name, time, and purpose information. Keep such files secure.
- If a file cannot be previewed online, it can still be downloaded as directed by the page.
- TXT/LOG, CSV, Markdown, JSON, XML, images, DOCX, and XLSX can be previewed on demand, including historical TXT metadata. Unsupported files such as anthem audio provide download only and do not show a folder preview control. Spreadsheet previews show at most 200 rows.

## Errors and Peak Traffic

- If the site shows “Peak Traffic,” OA functions have been paused temporarily to protect the daily service allowance. No account or business data is lost. Retry after the next 08:05 Beijing-time point shown on the page.

## Notifications

- The number on the bell indicates the unread notification count.
- Selecting a notification opens its complete details and automatically marks it as read.
- A notification may contain images, attachments, or an entry point to a related page.
- Read role changes, important branch decisions, and similar messages promptly.

## Account Security

- Do not share accounts, passwords, fee QR codes, or internal attachments with unrelated people.
- Contact a branch administrator if the displayed name, branch, or permissions are incorrect.
- If you notice an unusual sign-in or accidental operation, change the password and report the issue promptly.

## Accounts Without a Branch

- After removal from a former branch, the account, existing password, avatar, and historical responsibility records are not deleted.
- The account can still sign in, but only “My Profile” and guidance for contacting the system administrator are available until it joins a branch again.
- To join a new branch, contact its administrator. If the account is still shown as belonging to another branch, the platform prevents duplicate membership.
# 2.1 体验更新

平台通知中的图片和附件现在可直接查看；内容页面只显示发布者选择公开在附件区的文件。登录安全检测长时间无响应时可点击“重新进行安全检测”，不会降低账号安全校验。透明背景头像裁剪后将继续保留透明区域。
# 2.1 头像来源与安全检查

点击本人头像后可以恢复默认头像、填写公开 HTTPS 图片链接，或选择本地 JPG、PNG、WebP 文件。三种来源中的图片都使用同一个圆形裁剪工具；透明 PNG 会尽量保留透明区域。

图床链接不会直接长期加载。平台先检查地址是否为公开 HTTPS、是否发生跳转、返回内容是否为小于 1 MB 的真实图片；通过后才进入裁剪，并把最终头像保存到本站。若弹窗提示未采用，说明本次没有保存，请改用图片的最终直链或本地文件。
