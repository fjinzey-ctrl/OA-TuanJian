# 问题反馈指南

欢迎通过 GitHub Issues 报告问题或提出建议。

v2.1.9 更新了公开资料后台安全检测、平台用户表格、行为审计、支部删除流程和编辑器加载。反馈相关问题时请提供脱敏后的页面、浏览器、系统、设备类型、操作步骤和 `GMT+8:00` 时间，不要提供设备 Cookie、Turnstile token、会话值或账号密码。

## 建议提供

- 问题类型：功能异常、显示问题、操作建议或文档问题。
- 使用身份：成员、编辑、管理员或系统管理员。
- 使用设备：电脑或手机，并说明浏览器名称。
- 页面名称：例如公示栏、内容与附件、通知中心或支部详情。
- 操作步骤：从进入页面到出现问题的完整步骤。
- 发生时间：请注明北京时间。
- 预期结果与实际结果。
- 脱敏截图：遮挡姓名、学号、二维码、文件内容和通知附件。

## 请勿提供

- 密码、验证码或初始密码。
- 完整学号、成员名单或缴费记录。
- 内部公示、团建材料、支部备份或受保护附件。
- 能够直接访问内部内容的链接或登录信息。

## 建议标题

- `[功能异常] 手机端通知详情无法滚动`
- `[显示问题] 窄屏下某条长标题排列异常`
- `[功能建议] 希望归档列表增加年份筛选`

提交后请保留 Issue 编号，便于后续确认修复情况。

# Feedback Guide

You are welcome to report problems or propose improvements through GitHub Issues.

## Recommended Information

- Issue type: functional error, display problem, operation suggestion, or documentation problem.
- User role: member, editor, administrator, or system administrator.
- Device: computer or phone, including the browser name.
- Page: for example, Notices, Content and Attachments, Notification Center, or Branch Details.
- Steps: the complete sequence from opening the page to encountering the problem.
- Time: specify Beijing time.
- Expected result and actual result.
- Redacted screenshots: conceal names, student IDs, QR codes, file content, and notification attachments.

## Do Not Provide

- Passwords, verification codes, or initial passwords.
- Complete student IDs, member rosters, or payment records.
- Internal notices, activity materials, branch backups, or protected attachments.
- Links or credentials that provide direct access to internal content.

## Suggested Titles

- `[Functional Error] Notification details cannot scroll on mobile`
- `[Display Problem] A long title is arranged incorrectly on a narrow screen`
- `[Feature Suggestion] Add a year filter to the archive list`

After submission, keep the Issue number for later confirmation of the fix.
# 2.1 反馈定位补充

若安全检测超过约 12 秒仍未完成，请先使用页面内“重新进行安全检测”，并在反馈中附上浏览器、网络类型和发生时间。若通知附件无法打开，请同时提供通知标题与附件名称，不要转发受保护文件本身。
